# Алина · Твоя история в Хогвартсе

Личный сайт для Алины: письмо из Хогвартса, четыре факультета, уроки магии, ежедневные задания, карта замка и паспорт волшебницы. Работает в обычном браузере на телефоне. Бот и платный домен не нужны.

## Опубликовать бесплатно на GitHub Pages

1. Распакуй архив сайта на компьютере. **Загружать нужно распакованные файлы, а не сам ZIP.**
2. В GitHub создай **публичный** репозиторий, например `alina-hogwarts`. Публичного репозитория достаточно для GitHub Free.
3. Открой **Add file → Upload files** и перетащи всё содержимое распакованной папки. Файл `index.html` должен лежать в корне репозитория, рядом с `app.js`, `mobile.css` и папкой `assets`. Не помещай их в дополнительную вложенную папку.
4. Нажми **Commit changes**, сохрани файлы в ветку `main`.
5. Открой **Settings → Pages**. В блоке **Build and deployment** выбери **Source: Deploy from a branch**, **Branch: main**, папку **/(root)**. Нажми **Save**.
6. Когда публикация завершится, GitHub покажет ссылку. Для репозитория `alina-hogwarts` адрес будет `https://ТВОЙ-ЛОГИН.github.io/alina-hogwarts/`. Отправь эту ссылку Алине.

В **Custom domain** ничего вводить не нужно. Отдельный сервер, npm, сборка и GitHub Actions workflow для этого варианта не требуются. Если ветка репозитория называется иначе, выбери её вместо `main`.

Если исходный проект уже загружен целиком и `index.html` находится внутри `dist/`, используй отдельный репозиторий с содержимым папки экспорта: GitHub Pages в режиме публикации из ветки принимает корень или `/docs`, а не произвольную папку `dist`.

## На телефоне

Открой ссылку в Safari или Chrome. Можно добавить её на главный экран через меню браузера: на iPhone — «Поделиться → На экран Домой», на Android — пункт добавления на главный экран в меню. Это ярлык сайта; первое открытие и загрузка ресурсов требуют интернета.

Прогресс сохраняется в браузере устройства. Другой браузер, новый телефон, очистка данных или другой адрес сайта означают отдельное сохранение. Публичная ссылка не ограничивает доступ по имени: сайт персонализирован для Алины, но открыть его сможет любой, у кого есть ссылка.

## Изменить письмо

Открой `personalization.mjs`: имя, текст письма и подпись находятся в одном месте. Фотографий, контактов, токенов и других личных данных в публикации нет. Бот необязателен; если захочешь подключить Telegram, используй адрес GitHub Pages как адрес Mini App.
